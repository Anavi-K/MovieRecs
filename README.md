# 🎬 Movie Recommendation System

A full-stack movie recommendation app that recommends movies based on a selected movie.

### Features
- Hybrid recommendation system
- Content-based + collaborative filtering
- Movie posters, ratings, descriptions and release dates
- React frontend
- Flask backend
- TMDB API integration

### Tech Stack
React • Vite • Python • Flask • Pandas • Scikit-learn • TMDB API
